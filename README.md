## 一、开通 ChatGPT Plus 的几种方式

| 方式 | 需要准备 | 价格 | 主要问题 |
| --- | --- | --- | --- |
| 官网自己绑卡 | 能扣款的国际信用卡（Visa / Mastercard） | 美区 $20/月，另按账单地址加税 | 很多国内发的卡会被拒；失败多了同一个账号更难过 |
| iOS 应用内订阅 | 对应地区的 Apple ID 和余额 | 按 App Store 所在区定价 | 准备账号和余额步骤多 |
| 低价区官方价代充 | 一个没有订阅的 ChatGPT 账号、一台电脑 | 按菲律宾等地区官方价，Plus 一个月约 ¥115 | 只能给没有任何订阅的账号开 |
| 成品号 | 无 | 最便宜 | 是别人注册的新账号，聊天记录不在，封号一般不保 |
| 共享 / 拼车 | 无 | 便宜 | OpenAI 不允许共享，容易被封，隐私没保障，不建议 |

**怎么选：**

- 有能扣款的国际信用卡：官网自己订阅最省心。
- 有对应地区的 Apple ID 和余额：iOS 订阅。
- 都没有、想用支付宝微信付款：低价区官方价代充，充到你自己的账号。
- 只想短期试用或要副号：成品号，但一定看清质保。

## 二、代充靠不靠谱，看这 5 点

1. **要不要密码。** 正规的只需要在充值页粘贴一次 Session 识别账号，不要密码和验证码。充完可以在 ChatGPT 设置里「退出所有设备」让它失效。
2. **有没有官方订阅邮件和收据。** 充值成功后会收到 OpenAI 的订阅邮件，「设置 → 账单」里能看到订阅和收据。
3. **质保写没写清楚。** 「质保 30 天」「只保开通」「不质保」完全不同。
4. **账号条件写没写清楚。** 卡充一般只能给没有任何订阅的账号开；已经有订阅的要等到期，或者走 iOS 渠道（会覆盖原订阅）。
5. **充失败卡密作不作废。** 好的充值页会先检查账号，不符合条件不扣卡密。

**价格参考：** 美区官网 $20 加上税和卡的手续费，实际 ¥150 上下；低价区官方价一百一二十是正常的。明显低于这个价的，多问一句是不是充到你自己的账号、掉了怎么处理。

## 三、低价区代充的步骤（以 Plus 为例）

1. 付款后拿到一条**充值链接**，卡密就在链接里。
2. 在**电脑浏览器**打开（先在同一个浏览器登录 ChatGPT），按提示复制 Session 粘贴进去，页面会自动检查账号。
3. 核对账号邮箱后确认，一般 1～2 分钟到账。网页刷新、手机 App 重新打开就能看到订阅。

注意：账号**不能有任何订阅**（没有 Go、Plus、Pro，也没加入 Team）；充值完成前**不要退出** ChatGPT 登录。

## 常见问题

**低价区开的 Plus 和美区有区别吗？**
订阅、额度、功能都一样，只是按哪个国家的官方价付款，账单上可能显示当地货币。和你的账号在哪注册、人在哪都没有关系。

**已经有订阅还能代充吗？**
卡充要等现在的订阅到期；不想等可以走 iOS 渠道，会覆盖原订阅，剩余天数不累加。详见 [已有订阅还能代充吗](https://openmead.com/guides/chatgpt-topup-existing-plan/?utm_source=github&utm_medium=readme&utm_campaign=recharge-guide)。

**掉订阅了怎么办？**
先在「设置 → 账单」确认是不是真的掉了，再看买的是哪种质保。掉订阅和封号不是一回事，封号基本都不在质保范围。详见 [ChatGPT 掉订阅了怎么办](https://openmead.com/guides/chatgpt-subscription-dropped/?utm_source=github&utm_medium=readme&utm_campaign=recharge-guide)。
